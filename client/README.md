# MERN Job Portal

A production-ready Job Portal built using the MERN Stack.

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Framer Motion

### Backend

- Node.js
- Express
- MongoDB
- JWT
- Cloudinary

## Getting Started

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```

Frontend:
http://localhost:5173

Backend:
http://localhost:5000
